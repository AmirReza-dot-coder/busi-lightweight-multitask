# Scientific scope and open review items

- The base-paper settings notebook is a documented reconstruction; MobileNet variant, head details and other choices are explicit assumptions. No claim of exact replication or matched paper protocol is made.
- Historical component models begin from a shared BUSI-trained source. Seeds vary continuation randomness, not every starting weight independently. The controlled ST/MTL core instead starts with an ImageNet-only frozen CNN and fresh Transformer/heads.
- Historical test results were already inspected before later follow-ups. Those follow-ups use validation and remain exploratory. There is no new untouched external test in this package.
- The primary historical comparison was selected using validation. Both recorded 95% similarity-group-bootstrap intervals include zero. This is insufficient evidence of superiority and does not establish equivalence.
- ST/MTL classification and segmentation have separate checkpoint-selection rules. Combining their best scores as if generated by one checkpoint is invalid. The three seeds use the same validation images; their SD is not a patient-generalization confidence interval.
- Learned task weights are optimization coefficients, not per-prediction clinical uncertainty. ECE/Brier/NLL are probability-quality measures; MC-dropout/deep-ensemble uncertainty estimation was not implemented.
- LPRM coarse/final checks compare outputs within the same trained network. They do not replace an independently trained, matched no-LPRM control. No class labels or hard inconsistency counts changed in those three checks.
- A larger dataset might help, but data size was not independently varied in a controlled learning-curve experiment. No causal explanation for the Transformer ranking is established.
- The recorded inference profile uses batch 1, one seed, one T4 session, 10 warmups and 50 repeats. It includes output-to-host transfer and TensorFlow allocator memory, not total VRAM, image-file I/O, energy consumption or portable-device performance. The different timings of identically structured MTL checkpoints do not establish a stable speed ordering.

## Original closure flags are preserved

The original archive has 27 checkpoint records, 26 unique selected model files, 660 metric comparisons and two differences. The raw `closure_summary.json` status remains `REVIEW_REQUIRED`. Its `matching_checkpoints=25` refers to complete numerical matches for all compared metrics, not 25 out of 27 weights being loaded successfully. The exported checkpoint hashes identify 27 loaded records; full independent verification of those model bytes requires the actual `.keras` files.

The two flagged metrics are historical normal mean foreground percentages. Rechecking the archived hard-mask differences locates one-pixel changes; the area change per pixel in a 224×224 image is about 0.001993 percentage points, and averaging over 24 normal test images gives about 0.00008304 pp. The original numeric flags and model records remain available in `results/archives/` and `results/tables/`.

The new offline packaging checks recompute 288 class/hard-mask summary values from the archived predictions and references. Passing these checks demonstrates internal numerical consistency of those exported artifacts. It neither erases the original flags nor proves reproduction of training. Full soft-mask probabilities were not archived, so this package cannot independently recalculate BCE/soft-Dice losses from per-pixel probabilities.

## Files still needed for complete replay

Selected model bytes, historical initial model bytes, raw images and the full original Drive experiment layout remain external. The provided serialized Keras configurations document architecture, but configuration JSON alone does not restore a trained warm start or optimizer state. The checkpoint-export helper covers the selected models and principal initial model; preserve the original project directory for further training dependencies.

BUS-UCLM/external evaluation is proposed future work and has no results here. Targeted fine-tuning and LPRM-v2 source notebooks are marked exploratory; no new outcomes are invented for them.
